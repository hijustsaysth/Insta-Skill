具体能力

资料建设 / 自动互动 / 内容发布
账号基础建设skill

个人信息维护

对应原始需求2.个人信息维护。根据要求和素材生成头像、背景图、名字、简介。

输入

  • 账号id
  • access token/session之类支持api调用的标识信息
  • 可参考图片
  • 背景图尺寸
  • 主页个人名字约束提示词
  • 个人简介约束提示词

输出

  • 头像
  • 名字
  • 简介
  • api调用结果

流程

根据提示词生成账户名字 → 根据提示词生成个人简介 → 根据素材生成头像 → 根据素材、尺寸要求生成背景图
每日自动互动同类型视频skill

养号流程①1-5天

每天在各平台刷同类型短视频半小时并点赞、评论互动，避免系统识别人机号或营销号进行限流。

输入

  • 账号id
  • 关键词列表
  • 最多点赞数
  • 最多评论数
  • 评论风格提示词
  • 最小停留时间
  • 最大停留时间

输出

  • 日期
  • 运行时长
  • 观看数
  • 点赞数
  • 评论数
  • 执行日志

流程

关键词搜索 → 观看 → AI理解视频 → 点赞 → 生成评论 → 写入日志
发布内容skill

post / stories / reels

对应原始需求（5）②、③：每天发布1-2篇帖子 | 利用stories、reels等。

输入

  • 账号id
  • 发布类型（post/stories/reels）
  • 参考素材
  • 产品信息说明
  • 目标市场语言
  • 发布时间
  • 是否自动生成图片/视频

输出

  • 结果：状态、时间、失败原因、post id
  • 生成内容：类型、tag、正文、图片/视频

流程

生成基本亮点说明 → 按发布类型生成内容 → 内容检查 → 人工审批 → 发布 → 结果回写

技术路线层

按 skill 归类
账号基础建设skill

aiograpi

aiograpi 是直接调用 Instagram Private API 的异步 Python SDK，部署相对简单，只需要在 Python 环境中安装依赖即可，适合需要直接控制 SDK、调试新接口或快速补能力的场景。

它的优势是能力覆盖最完整、更新通常更快；缺点是上层系统需要自己处理 Session、Proxy、Challenge、异常恢复以及 Tool 封装。

账号基础建设skill / 发布内容skill

aiograpi-rest

aiograpi-rest 是把 aiograpi 封装成 HTTP REST 服务的项目，本质上仍然调用 Instagram Private API，但对外提供统一的 REST/OpenAPI 接口。

如果只做能力验证，优先aiograpi-rest。由于是非官方api，为了降低封号风险，需要复用用户session避免持续、频繁产生新的登录行为，从而触发风控。

账号基础建设skill / 发布内容skill

Instagram connector

api不可用时的兜底。

每日自动互动同类型视频skill

Instagram connector + Host Runtime

编写Instagram connector，实现操作组件节点完成指定动作（搜索reels、点赞、评论、滑动等），调用组件节点失败时，使用截图+识别坐标兜底。

每日自动互动同类型视频skill

Android Accessibility Script Pack 脚本

ven-coder/assists：封装Accessibility，提供更高层API，可以通过MCP暴露能力。

每日自动互动同类型视频skill

Playwright 脚本

vrajdesai78/instagram-skill：提供关键词搜索、reels搜索传参hashtag和tab（top/recent/clips）。
