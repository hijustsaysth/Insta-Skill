Instagram养号skills架构原型

根据 海外社媒运营流程-12.31.pdf：一、社媒六大平台介绍及养号流程 整理了Instagram养号skills的初版方案

来源：Instagram养号skills.md

总体架构

总编排能力 → 具体能力 → 执行结果

输入

  • 账号id
  • 注册日期
  • 当前日期
  • access token
  • 目标市场
  • 素材库路径
→

养号skill

根据账号注册日期，识别养号阶段，选择具体动作

→
账号基础建设skill 生成头像、背景图、名字、简介
每日自动互动同类型视频skill 搜索、观看、识别、点赞、评论、写入日志
发布内容skill 生成并发布post/stories/reels，结果回写

总编排能力

养号skill

定位

对应原始需求（5）：养号

流程

根据注册日期识别养号阶段 → 生成今日任务计划 → 调用子skill → 执行 → 输出结果

输出

  • 日期
  • 当前阶段
  • 今日任务列表
  • 调用skill
  • 每个任务的执行结果
  • 执行日志（日志内容根据阶段对应的skill而定）
  • 下一次建议执行时间

具体能力

账号基础建设 / 每日自动互动 / 发布内容
账号基础建设skill

个人信息维护

根据要求和素材生成头像、背景图、名字、简介

输入

  • 账号id
  • access token
  • 可参考图片
  • 背景图尺寸
  • 主页个人名字约束提示词
  • 个人简介约束提示词

输出

  • 头像
  • 背景图
  • 名字
  • 简介

流程

根据提示词生成账户名字 → 根据提示词生成个人简介 → 根据素材生成头像 → 根据素材、尺寸要求生成背景图
每日自动互动同类型视频skill

养号流程①1-5天

每天在各平台刷同类型短视频半小时并点赞、评论互动，避免系统识别人机号或营销号进行限流。

输入

  • 账号id
  • 关键词列表
  • 最多点赞数
  • 最多评论数
  • 评论风格提示词
  • 最小停留时间
  • 最大停留时间

输出

  • 日期
  • 运行时长
  • 观看数
  • 点赞数
  • 评论数
  • 执行日志

流程

关键词搜索 → 观看 → AI理解视频 → 点赞 → 生成评论 → 写入日志
发布内容skill

帖子 / stories / reels

根据产品素材、历史内容生成文字、图片、视频并发布post/stories/reels

输入

  • 账号id
  • 发布类型（post/stories/reels）
  • 参考素材
  • 产品信息说明
  • 目标市场语言
  • 发布时间
  • 是否自动生成图片/视频

输出

  • 结果
  • 状态
  • 时间
  • 失败原因
  • post id
  • 生成内容

流程

生成基本亮点说明 → 按发布类型生成内容 → 内容检查 → 人工审批 → 发布 → 结果回写

能力清单

Tool 级能力
视频搜索tool 输入：关键词；输出：url
视频识别tool 输入：url、目标说明；输出：是否符合目标、是否点赞、是否评论
点赞tool 输入：无；输出：结果状态、时间
评论tool 输入：评论内容；输出：结果状态、时间
Post生成 Tool 发布内容skill能力
Stories生成 Tool 发布内容skill能力
Reels生成Tool 发布内容skill能力
发布Tool / 发布状态查询Tool 发布内容skill能力

技术方案

每日自动互动同类型视频skill

Instagram connector + Host Runtime

编写Instagram connector，实现操作组件节点完成指定动作（搜索reels、点赞、评论、滑动等），调用组件节点失败时，使用截图+识别坐标兜底

Android Accessibility Script Pack 脚本

ven-coder/assists：封装Accessibility，提供更高层API，可以通过MCP暴露能力

Playwright 脚本

vrajdesai78/instagram-skill：提供关键词搜索、reels搜索传参hashtag和tab（top/recent/clips）
