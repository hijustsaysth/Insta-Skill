Instagram养号skills架构原型

根据 海外社媒运营流程-12.31.pdf：一、社媒六大平台介绍及养号流程，整理 Instagram 养号 skills 的初版方案。

来源：my_work/Instagram养号skills.md

总体架构

输入 → 养号skill → 子skill → 输出

输入

  • 账号id
  • 注册日期
  • 当前日期
  • access token/session之类支持api调用的标识信息
  • 语言要求
  • 素材库路径
→

养号skill

根据账号注册日期，识别养号阶段，选择具体动作。

→
账号基础建设skill 根据要求和素材生成头像、背景图、名字、简介
每日自动互动同类型视频skill 关键词搜索、观看、AI理解视频、点赞、生成评论、写入日志
发布内容skill 生成文字、图片、视频并发布 post / stories / reels
→

输出

  • 日期
  • 当前阶段
  • 今日任务列表
  • 调用skill
  • 每个任务的执行结果
  • 执行日志
  • 下一次建议执行时间

总编排能力

养号skill

定位

对应原始需求（5）：养号

流程

根据注册日期识别养号阶段 → 生成今日任务计划 → 调用子skill → 执行 → 输出结果

能力

  • 账号基础建设skill
  • 每日自动互动同类型视频skill
  • 发布内容skill

具体能力

三个子 skill 的职责、输入输出与流程
账号基础建设skill

个人信息维护

对应原始需求2.个人信息维护。根据要求和素材生成头像、背景图、名字、简介。

输入

  • 账号id
  • access token/session之类支持api调用的标识信息
  • 可参考图片
  • 主页个人名字约束提示词
  • 个人简介约束提示词

输出

  • 头像
  • 名字
  • 简介
  • api调用结果

流程

生成账户名字 → 生成个人简介 → 生成头像 → 生成背景图
每日自动互动同类型视频skill

养号流程①1-5天

每天在各平台刷同类型短视频半小时并点赞、评论互动，避免系统识别人机号或营销号进行限流。

输入

  • 账号id
  • 关键词列表
  • 最多点赞数
  • 最多评论数
  • 评论风格提示词
  • 最小停留时间
  • 最大停留时间

输出

  • 日期
  • 运行时长
  • 观看数
  • 点赞数
  • 评论数
  • 执行日志

流程

关键词搜索 → 观看 → AI理解视频 → 点赞 → 生成评论 → 写入日志
发布内容skill

post / stories / reels

对应原始需求（5）②、③：每天发布1-2篇帖子 | 利用stories、reels等。

输入

  • 账号id
  • 发布类型（post/stories/reels）
  • 参考素材
  • 产品信息说明
  • 目标市场语言
  • 发布时间
  • 是否自动生成图片/视频

输出

  • 结果：状态、时间、失败原因、post id
  • 生成内容：类型、tag、正文、图片/视频

流程

生成亮点说明 → 生成内容 → 内容检查 → 人工审批 → 发布 → 结果回写

工具层能力

各 skill 暴露的 tool
个人资料编辑tool 输入：头像、名字、简介；输出：结果状态
视频搜索tool 输入：关键词；输出：url
视频识别tool 输入：url、目标说明；输出：是否符合目标、是否点赞、是否评论
点赞tool 输入：无；输出：结果状态、时间
评论tool 输入：评论内容；输出：结果状态、时间
Post生成 Tool 发布内容skill能力
Stories生成 Tool 发布内容skill能力
Reels生成Tool / 发布Tool / 发布状态查询Tool 发布内容skill能力

技术路线层

所有技术方案统一归入本层
适用 skill 技术方案 文档说明 定位
账号基础建设skill aiograpi aiograpi 是直接调用 Instagram Private API 的异步 Python SDK，部署相对简单，只需要在 Python 环境中安装依赖即可，适合需要直接控制 SDK、调试新接口或快速补能力的场景。优势是能力覆盖最完整、更新通常更快；缺点是上层系统需要自己处理 Session、Proxy、异常恢复以及 Tool 封装。 SDK 直连能力
账号基础建设skill aiograpi-rest aiograpi-rest 是把 aiograpi 封装成 HTTP REST 服务的项目，本质上仍然调用 Instagram Private API，但对外提供统一的 REST/OpenAPI 接口。更适合 Agent、Skill、MCP、Java/Go/Node 后端或多服务架构。支持 Docker 部署、开箱即用。 能力验证优先方案
账号基础建设skill Instagram connector api不可用时的兜底。 兜底
每日自动互动同类型视频skill Instagram connector + Host Runtime 编写Instagram connector，实现操作组件节点完成指定动作（搜索reels、点赞、评论、滑动等），调用组件节点失败时，使用截图+识别坐标兜底。 组件节点操作与截图识别兜底
每日自动互动同类型视频skill Android Accessibility Script Pack 脚本 ven-coder/assists：封装Accessibility，提供更高层API，可以通过MCP暴露能力。 移动端自动化脚本
每日自动互动同类型视频skill Playwright 脚本 vrajdesai78/instagram-skill：提供关键词搜索、reels搜索传参hashtag和tab（top/recent/clips）。 Web 自动化脚本
发布内容skill 官方API 最安全、风险最低。但是只支持专业账号。 优先发布路线
发布内容skill aiograpi-rest 非官方API，支持普通账号。可以作为非专业账号的兜底方案。 普通账号兜底方案
发布内容skill Instagram connector api失效时的兜底。 兜底
